## How I work on AI projects

1. **Scope honestly.** Every case study ends with its limits: synthetic data, unmeasured estimates, demos that are only illustrations.
2. **Measure against a baseline.** A rule-based baseline before the LLM, a blind guess before the model, a pass/fail threshold set before training the challenger.
3. **Keep the human decision human.** The tools I build and assess show evidence and recommend; people decide.
